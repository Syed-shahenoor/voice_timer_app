# 🎙️ Voice Timer App

A simple voice-controlled timer application built using **HTML**, **CSS**, and **JavaScript**. The application uses the browser's **Web Speech API** to recognize voice commands and control the timer without requiring manual interaction.

## Features

- Start the timer using voice commands
- Pause the timer using voice commands
- Restart the timer using voice commands
- Voice recognition powered by the Web Speech API
- Simple and user-friendly interface

## Tech Stack

- HTML
- CSS
- JavaScript
- Web Speech API

## Installation

### Clone the repository

```bash
git clone https://github.com/Syed-shahenoor/voice_timer_app.git
```

### Navigate to the project directory

```bash
cd voice_timer_app
```

### Run the application

Open `index.html` in a supported web browser (Google Chrome is recommended).

## Voice Commands

The application recognizes the following commands:

- **Start** – Starts the timer.
- **Pause** – Pauses the timer.
- **Restart** – Resets and starts the timer again.
